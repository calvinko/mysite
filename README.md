# Calvin Personal Website

A ready-to-run React + Vite + Tailwind personal website.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Build for web server

```bash
npm run build
```

Upload the contents of the generated `dist/` folder to your web server.

For Apache/Nginx static hosting, the important output files are:

```text
dist/index.html
dist/assets/
```

## Edit content

Most website content is in:

```text
src/App.jsx
```
